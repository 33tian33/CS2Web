# 四校 CS2 联赛初步赛制

本文记录初次建赛的历史配置。现有赛事请使用 [世界杯赛制迁移](WORLDCUP_FORMAT.md)，保留已经调整的分组、人员及赛果；下方初始化脚本会重建赛事，不用于日常更新。

- 复旦大学、华东师范大学、上海交通大学、同济大学各12队，暂名为学校简称加1–12队；所有队员清空。
- A–L共12组，每组四校各一队，按同编号初步分组。
- 小组单循环BO2，打满两图，胜3分、平1分、负0分，共72场。
- 每组前两名直通，共24队；12个第三名按积分、净胜图、净胜回合降序比较，前8名晋级，组成32强。
- 组内沿用积分、净胜图、净胜回合、相互战绩；仍同分由管理员裁定。跨组前三项全同分时，现有比较器按队名、队伍编号排序。
- 32强单淘共31场，默认BO3，决赛单场设为BO5。两场半决赛败者进入BO3季军赛，总计104场。
- 初版首轮曾按第三名跨组名次直接落位；现已改用2026世界杯官方对阵及495种第三名晋级组合表，初始化脚本也采用这一规则。
- 日期、地点、赛季和时间暂留空；全部比赛未开始，无BP、赛果或选手数据。

## 同步

本地数据已写入 `data/tournament.sqlite3` 并启用三个赛段。访问 http://127.0.0.1:5173/#/event，在“赛段与晋级”切换小组赛、32强单淘汰和季军赛。后台可调整分组、晋级来源和每场BO数。

另行部署时，可上传项目和初始化脚本，然后在目标项目目录执行：

```bash
python3 scripts/apply_initial_format.py --database /实际路径/tournament.sqlite3
```

此操作先备份目标库，再替换尚未开赛的队伍、赛程并清空队员。已有BP或赛果时拒绝覆盖，不要在每次启动时执行。本次仅同步本地网站，未操作腾讯云服务器。
