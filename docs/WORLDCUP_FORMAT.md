# 2026 世界杯晋级与淘汰赛

本项目采用 FIFA 2026 世界杯的晋级名额、32强对阵、第三名组合分配，以及16强至决赛和季军赛的固定路径。现有 A–L 分组、队员、小组赛数据、CS2 积分与同分排序、各场 BO 和比赛时间保留。

## 官方来源

[FIFA World Cup 26 Regulations，2026年5月版](https://digitalhub.fifa.com/m/636f5c9c6f29771f/original/FWC2026_regulations_EN.pdf)，第12.5–12.11条及附录C。`rules/worldcup2026.json` 保存附录C全部495种分配，包含来源地址、版本和原文件 SHA-256。键为晋级第三名所属的8个小组字母（排序后）；值按 A、B、D、E、G、I、K、L 组第一的顺序，记录各自第三名对手所属小组。

前二直接晋级；12个第三名按现有CS2规则选出前8名。只有相关小组全部完赛、组内第三名明确后，才按晋级小组组合查表分配，第三名的跨组名次不决定对阵位置。

小组赛进行中，前台淘汰赛图按当前积分自动预览32强对阵：每组前二及当前成绩最好的8个第三名进入预览，第三名仍按附录C组合查表安排走位。队伍旁标注当前小组名次，卡片显示“暂定对阵”；完全同分时沿用积分表的展示顺序。预览随赛事数据刷新，不写入正式比赛、不影响后台或已确定对阵，小组赛完赛且名次明确后切换为正式对阵。

## 对阵图

淘汰赛页面将季军战与决赛放入同一张完整对阵图，实线表示胜者晋级，铜色虚线表示半决赛败者进入季军战。每轮完赛进度推动视野逐渐右移，最终居中展示决赛与季军战。支持鼠标双向拖动、触屏滚动及“回到当前赛程”；进度未变化时，页面更新保留手动查看位置。轮次标题固定，比赛卡片展示数据库比赛编号、单场BO、比分、状态和时间，点击进入对应比赛。

季军赛仍是独立的比赛与后台赛段，仅在前台合并展示；分组、晋级来源、比分和比赛ID均不改变。样式和交互由 `public/knockout.css`、`public/knockout.js` 提供，部署时需同时上传。

## 更新现有赛事

先备份线上程序和数据库，停止服务，更新 `server.py`、`tournament.py`、`worldcup.py`、`rules/`、完整 `public/` 和 `scripts/`，再在项目目录执行：

```bash
python3 scripts/apply_worldcup_format.py --database /实际路径/tournament.sqlite3
```

脚本自动备份到数据库旁的 `backups/`，在事务中更新当前启用赛制和草稿，检查分组、人员、小组赛数据及数据库完整性。保留所有比赛ID、时间、BO；有淘汰赛已开始或已有BP、赛果时拒绝变更。重复执行已完成的迁移不会重复写入。完成后重新启动服务；只更新前端文件无法启用此规则。

不要对现有赛事运行 `apply_initial_format.py`：该脚本用于重建初始赛事，会清空人员和比赛。

回滚时停止服务，恢复本次脚本输出的数据库备份以及更新前的程序文件，再启动服务。部署包必须包含新增的 `worldcup.py` 和 `rules/`。
